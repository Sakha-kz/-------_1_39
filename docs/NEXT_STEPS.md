# Что делать сейчас

1. Откройте Google Colab: https://colab.research.google.com/.
2. Нажмите «Загрузить блокнот» и выберите `notebooks/00_Start_Here.ipynb` из архива.
3. Включите T4 GPU через «Среда выполнения → Сменить среду выполнения».
4. Выполните ячейки сверху вниз и разрешите подключение собственного Drive.
5. Выполните ячейку smoke-варианта 29. Это проверка установки и записи файлов.
6. Если ошибки нет, запустите вариант 1 со списком `VARIANTS=[1]` в следующей ячейке.
7. Для разбора ошибки отправьте полный traceback и вывод `environment()`.
   Для подготовки окончательного отчёта нужны исполненные `.ipynb`, JSON и рисунки.

Сначала завершаем один полноразмерный вариант и проверяем фактическую
совместимость Colab, загрузок и чекпоинтов. Затем тем же кодом запускаются все
остальные 38. Это порядок исполнения, а не сокращение объёма задания.

Отдельно откройте `Poetry_Colab.ipynb`: первая часть фиксирует исходный notebook,
вторая готовит корпус и запускает fine-tuning. Названия колонок заполняются после
просмотра заголовка фактического TSV. Если исходный notebook не скачивается и
в Colab, загрузите его через File → Download .ipynb из заданной ссылки и сохраните
в папку poetry; точное воспроизведение до этого момента не подтверждено.

Пакет не публиковался в GitHub. В нём нет придуманной ссылки на новый репозиторий,
чужого видео-приветствия или вымышленных результатов обучения.

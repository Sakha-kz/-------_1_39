# Отчёт по компьютерному зрению и дообучению Persian GPT-2

## Цель работы

Разработка и исследование полного цикла классификации изображений для 39 вариантов: данные, классические признаки, нейросети, обучение, оценка, интерпретация и перенос. Отдельная часть посвящена адаптации Persian GPT-2 к поэтическому корпусу.

## Реализованные методы

Предусмотрены HOG, LBP, HSV, Hu и SIFT-BoW с SVM/kNN; SmallCNN, LeNet, MLP, ResNet, MobileNet, DenseNet, EfficientNet и ViT. Специальные сценарии включают few-shot, дисбаланс, domain adaptation, дистилляцию, pruning/INT8 и SSL.

## Воспроизводимость

Seed обучения определяется как 1000 + номер варианта; у сравниваемых пар зафиксирован общий seed данных. Чекпоинты включают состояние обучения и генераторов случайных чисел.

## Результаты локальной проверки

Успешно выполнено модульных проверок: 22. Проверены resume, BatchNorm в linear probe, функции потерь, разбиение данных и маскирование padding.

Проверочный эксперимент №29 выполнен на CPU: 120 обучающих и 48 validation-изображений, по две эпохи для none и policy.

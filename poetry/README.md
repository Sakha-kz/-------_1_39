# Отчёт по Persian Poetry Fine-Tuning

## Цель исследования

Адаптация авторегрессионной языковой модели к корпусу персидской поэзии и
сравнение её поведения до и после дообучения.

## Модель и данные

В реализации используется базовая модель HooshvareLab/gpt2-fa и открытый
Chronological Persian Poetry Dataset. Готовая gpt2-fa-poetry не заменяет
процедуру обучения. Предусмотрена фиксация ревизии модели, hash исходного TSV,
размеров выборок и идентификаторов полных стихотворений.

## Методика

Дубликаты стихотворений удаляются; разделение train/validation выполняется
до токенизации. Тексты преобразуются в неперекрывающиеся блоки токенов.
Padding исключается из функции потерь с помощью attention mask, при этом
настоящий EOS остаётся целевой меткой. Используются gradient accumulation,
gradient checkpointing и сохранение состояния для resume.

## Оценка

Протокол включает held-out token loss и perplexity, а также генерации до и после
обучения при одинаковых prompts, seed и параметрах декодирования.

## Результаты и выводы

Подготовлены реализация и Colab-ноутбук. Полноразмерный запуск fine-tuning
в текущем комплекте результатов не представлен. Улучшение качества модели
численно не установлено. Сверка адаптации с исходным notebook не подтверждена.
Perplexity характеризует предсказание токенов и не является самостоятельной
оценкой художественного качества стихотворения.
